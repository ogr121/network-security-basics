# Basic Network Security Checklist

Tick each item when it is complete. Mark failed items and record a fix date.

## 1. Inventory
- [ ] A list of all devices on the network is kept
- [ ] Unknown devices are checked and removed
- [ ] A simple network diagram exists and is up to date

## 2. Passwords and access
- [ ] Default passwords on routers, switches and cameras are changed
- [ ] Strong passwords are required
- [ ] Multi-factor authentication is on for admin and remote access
- [ ] Users only have the access they need (least privilege)
- [ ] Accounts of former staff are disabled

## 3. Firewall
- [ ] Firewall is turned on and uses default deny
- [ ] Unused ports and services are closed
- [ ] Firewall rules are reviewed every six months
- [ ] Firewall firmware is up to date

## 4. Segmentation and Wi-Fi
- [ ] Guest Wi-Fi is separate from the staff network
- [ ] Servers are on their own network segment
- [ ] Wi-Fi uses WPA3 or WPA2 with a strong passphrase
- [ ] Router admin pages are not open to the internet

## 5. Updates
- [ ] Operating systems and software are patched
- [ ] Router and switch firmware are updated
- [ ] Antivirus is installed and updating

## 6. Monitoring and backup
- [ ] Logs are collected and checked
- [ ] Alerts are set for repeated failed logins
- [ ] Backups run regularly and one copy is offline
- [ ] A restore test was done in the last six months

## 7. People and response
- [ ] Staff get phishing and security awareness training
- [ ] There is a simple incident response plan
- [ ] Staff know who to tell when something looks wrong
